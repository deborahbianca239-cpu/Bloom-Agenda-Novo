## 🌸 Bloom Agenda

O **Bloom Agenda** é um projeto de cronograma pessoal desenvolvido para ajudar na organização da rotina diária. A ideia é oferecer uma forma simples e prática de anotar tarefas e manter o dia mais organizado.

###  Sobre o projeto

Este projeto consiste em uma agenda digital online onde o usuário pode gerenciar suas tarefas de forma eficiente. Com uma interface simples e intuitiva, o sistema permite organizar atividades por dia da semana e horário.

### Funcionalidades

* Criar conta de usuário (cadastro)
* Fazer login
* Recuperar senha
* Adicionar tarefas
* Visualizar tarefas por dia da semana
* Editar tarefas
* Excluir tarefas
* Marcar tarefas como concluídas

###  Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Supabase (banco de dados e autenticação)

###  Objetivo

O objetivo do Bloom Agenda é ajudar pessoas a organizarem melhor sua rotina, aumentando a produtividade e facilitando o controle de tarefas do dia a dia.

### Público-alvo

Estudantes, profissionais e qualquer pessoa que deseja melhorar sua organização pessoal.

###  Como usar

1. Acesse o site do projeto
2. Crie uma conta ou faça login
3. Adicione suas tarefas
4. Organize seu dia de forma prática

### Acesso

O sistema pode ser acessado diretamente pelo navegador, sem necessidade de instalação.
